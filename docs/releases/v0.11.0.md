# Release Notes: v0.11.0

**Release Date:** 2026-10-08

## Summary

This release adds an [OmniMail](https://github.com/plexusone/omnimail) sender
for Amazon SES v2. Applications that send transactional email through the
`omnimail.Sender` interface (verification links, security notices, receipts)
can now deliver through SES by changing only how the sender is constructed.
It also fixes an integer overflow in the OmniMemory DynamoDB provider.

## Highlights

- Amazon SES v2 sender implementing `omnimail.Sender`.
- Raw MIME delivery, so messages arrive exactly as `omnimail.BuildMIME` builds
  them.
- SES message tags, configuration sets, and cross-account sending
  authorization.
- SES errors classified into omnimail error kinds, with `Retry-After`.
- Passes the omnimail `providertest` conformance suite.

## What's New

### Features

#### OmniMail Amazon SES Sender

The new `omnimail` package implements `omnimail.Sender` on the SES v2
`SendEmail` API:

```go
import (
    "github.com/plexusone/omnimail"
    ses "github.com/plexusone/omni-aws/omnimail"
)

sender, err := ses.New(ses.Config{
    Region:               "us-east-1",
    ConfigurationSetName: "transactional", // optional
    DefaultTags:          map[string]string{"app": "web"},
})

res, err := sender.Send(ctx, &omnimail.Message{
    From:    omnimail.Address{Name: "Example", Email: "no-reply@example.com"},
    To:      []omnimail.Address{{Email: "user@example.org"}},
    Subject: "Verify your email",
    Text:    "Open this link to verify your address: https://example.com/verify?t=...",
    Tags:    map[string]string{"purpose": "verify_email"},
})
if err != nil && omnimail.IsRetryable(err) {
    // retry after omnimail.RetryAfter(err)
}
```

- **Raw MIME:** messages are assembled by `omnimail.BuildMIME` and sent as
  `Content.Raw`, so custom headers, Reply-To, Unicode subjects and display
  names, and text/HTML bodies are delivered as built. To, Cc and Bcc go in
  the SES destination, which keeps Bcc out of the headers.
- **Message tags:** `Message.Tags` and `Config.DefaultTags` become SES
  message tags for event publishing, validated against SES tag rules.
- **Options:** configuration set, sending authorization identity ARN
  (`FromEmailAddressIdentityArn`), feedback forwarding address, and SDK retry
  attempts (`MaxAttempts`).
- **Errors:** `Classify` maps SES error codes to omnimail kinds (rejected,
  throttled, transient, auth and others), with `Retry-After` when SES sends
  one.
- **Addresses:** SES does not support SMTPUTF8, so non-ASCII addresses are
  rejected as `KindInvalidAddress` before sending.

### Fixes

- **OmniMemory DynamoDB:** a query `Limit` above `math.MaxInt32` overflowed
  the `int32` conversion. The page size is now capped at `math.MaxInt32-1`,
  which leaves room for the extra item requested to detect `HasMore`. A zero
  or negative limit still means 100.

## Dependencies

- Adds `github.com/plexusone/omnimail` v0.1.0.
- Adds `github.com/aws/aws-sdk-go-v2/service/sesv2` v1.78.0.
- Updates the aws-sdk-go-v2 modules to the v1.47.1 release set and
  `smithy-go` to v1.28.4.

## Migration Guide

### From v0.10.0

There are no breaking changes. This release only adds the SES sender and a
fix.

To send through SES, replace the sender you construct, such as `smtp.New`,
with `ses.New`. Code that calls `Send` is unchanged.
