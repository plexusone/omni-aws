## [v0.11.0] - 2026-10-08

### Highlights

- OmniMail Amazon SES v2 sender for transactional email

### Added

- [omnimail] Amazon SES v2 sender implementing `omnimail.Sender`, delivering raw MIME built by `omnimail.BuildMIME` through `SendEmail` ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))
- [omnimail] SES message tags from `Message.Tags` and `Config.DefaultTags`, validated against SES tag rules ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))
- [omnimail] Configuration set, sending authorization identity ARN, and feedback forwarding address options ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))
- [omnimail] `Classify` maps SES error codes to omnimail error kinds with `Retry-After` support ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))
- [omnimail] Non-ASCII addresses rejected as `KindInvalidAddress` because SES does not support SMTPUTF8 ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))

### Fixed

- [omnimemory] DynamoDB query `Limit` above `math.MaxInt32` no longer overflows the `int32` conversion; the page is capped at `math.MaxInt32-1` ([`02c5744`](https://github.com/plexusone/omni-aws/commit/02c5744))

### Dependencies

- Add `github.com/aws/aws-sdk-go-v2/service/sesv2` v1.78.0 for the OmniMail SES sender ([`591889a`](https://github.com/plexusone/omni-aws/commit/591889a))
- Update aws-sdk-go-v2 modules to the v1.47.1 release set and `smithy-go` to v1.28.4, and other dependencies to their latest releases ([`03a60bf`](https://github.com/plexusone/omni-aws/commit/03a60bf))
- Add `github.com/plexusone/omnimail` v0.1.0 ([`03a60bf`](https://github.com/plexusone/omni-aws/commit/03a60bf))

### Documentation

- [omnimail] SES sender guide with error mapping, IAM policy, and SES sandbox, DKIM, SPF and DMARC setup ([`611b6f9`](https://github.com/plexusone/omni-aws/commit/611b6f9))
- Add OmniMail package links to README, docs index, and MkDocs navigation ([`611b6f9`](https://github.com/plexusone/omni-aws/commit/611b6f9))

### Tests

## [v0.8.0] - 2026-05-03

### Highlights

- OmniVault AWS providers consolidated into omni-aws monorepo
- AWS Secrets Manager and Parameter Store support for secret management

### Breaking

- [omnivault] Module path changed from `github.com/plexusone/omnivault-aws` to `github.com/plexusone/omni-aws/omnivault`

### Upgrade Guide

- Update import paths from `github.com/plexusone/omnivault-aws` to `github.com/plexusone/omni-aws/omnivault`
- Update import paths from `github.com/plexusone/omnivault-aws/secretsmanager` to `github.com/plexusone/omni-aws/omnivault/secretsmanager`
- Update import paths from `github.com/plexusone/omnivault-aws/parameterstore` to `github.com/plexusone/omni-aws/omnivault/parameterstore`

### Added

- [omnivault] AWS Secrets Manager provider implementing `vault.Vault` and `vault.ExtendedVault` interfaces
- [omnivault] AWS Parameter Store provider implementing `vault.Vault` interface
- [omnivault] Convenience functions `NewSecretsManager()` and `NewParameterStore()` for quick setup
- [omnivault] Support for custom AWS config, region, profile, and endpoint URL
- [omnivault] JSON parsing for Secrets Manager secrets with field extraction
- [omnivault] Version staging labels support for Secrets Manager
- [omnivault] Path prefix support for Parameter Store namespacing
- [omnivault] Secret rotation trigger for Secrets Manager
- [omnivault] Version history retrieval for both providers

### Changed

- Migrated from standalone `omnivault-aws` repository (v0.2.0) into omni-aws monorepo

### Internal

- Previous omnivault-aws releases: v0.1.0 (initial), v0.2.0 (org rename)

## [v0.7.0] - 2026-04-25

### Highlights

- Consolidated to single Go module at repository root
- Unified AWS provider package with both LLM (Bedrock) and Storage (S3) adapters

### Breaking

- Module path changed from `github.com/plexusone/omni-aws/omnillm` to `github.com/plexusone/omni-aws`
- Module path changed from `github.com/plexusone/omni-aws/omnistorage` to `github.com/plexusone/omni-aws`

### Upgrade Guide

- Import paths remain the same: `github.com/plexusone/omni-aws/omnillm` and `github.com/plexusone/omni-aws/omnistorage`
- Run `go get github.com/plexusone/omni-aws@v0.7.0` to update dependency

### Changed

- Removed nested `omnillm/go.mod` and `omnistorage/go.mod` in favor of root-level `go.mod`
- Consolidated changelogs from per-module to single repository changelog
- Simplified CI workflows (removed multi-module configuration)

### Internal

- Previous releases: `omnillm/v0.6.0` (Bedrock adapter), `omnistorage/v0.1.0` (S3 adapter)
